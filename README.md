# STRTGY-CTRL (Strategy Module)

Strategic planning and campaign strategy management for senior leadership.

## Crates

| Crate | Description |
|-------|-------------|
| `strategy` | Campaign strategy, objectives, end-states |
| `strategy-server` | Unified server for strategy features |

## Target Users

- **Strategic Planners**
- **Campaign Designers**
- **Senior Leadership**

## Features

- Campaign objective definition
- Strategic end-state planning
- Lines of operation
- Phase planning

## Quick Start

```bash
cargo build --workspace
cargo run -p strategy-server
```
